# VouliMatch — Greek Parliamentary Vote Matching Tool

**Live Demo:** [voulimatch.vercel.app](https://voulimatch.vercel.app)

An interactive, politically neutral web application that aligns user stances on actual legislative bills with the official voting records of Greek parliamentary parties.

## Key Features & Architecture
* **Data-Driven Matching:** Compares user responses against real parliamentary votes to calculate party alignment percentages.
* **Lightweight & Fast:** Built with **Next.js 14**; legislative data is loaded statically from structured JSON files in `/data` without requiring an external database.
